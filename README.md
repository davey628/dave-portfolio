# Dave Lawrence A. Peralta — Personal Portfolio

Responsive static website; no build, database or credentials required. Open `index.html` locally, or serve with `python -m http.server 8000`.

## GitHub Pages
1. Create a public repository, e.g. `portfolio`.
2. Upload all extracted contents, including the `assets` folder and `.nojekyll`, to the repository root. Keep `index.html` at the root.
3. Commit to `main`, then Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Open the URL GitHub displays after publishing.

## Files
- `index.html`: portfolio content
- `style.css`: styling, responsive and print layouts
- `script.js`: theme, navigation, image gallery, email copy and print controls
- `resume.html`: public printable résumé
- `assets/`: own original portrait, actual DSP screenshots and favicon
- `.nojekyll`: bypass Jekyll processing

Use the Print / Save as PDF buttons for paper printing or PDF export. Graduation remains expected in 2027. Other projects have no supplied media; add genuine screenshots or video later. No private street address, phone number, signature or original application documents are included. Review public-facing content before publishing.
